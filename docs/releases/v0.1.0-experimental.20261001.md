# Experimental Windows baseline before context-engine work

This prerelease collects the changes completed before the GitHub #39 context-engine implementation. It preserves the Neural experimental TSF pipeline and the existing continuation-based runtime. FIM is not enabled or included in this baseline.

Changes include progressive Chinese candidate paging, exact-spelling and multi-token pinyin search, bounded lexical supplements, immutable score snapshots, context-refresh preemption, quantization-aware runtime selection, and larger bounded TSF context transport. Q8 remains supported; Q4 is an optional runtime choice. The launcher includes a fullscreen game supervisor.

Release review also corrected two lifecycle defects: private/session invalidation now releases lexical cursors through the full inheritance chain and rejects late cursor writes; the supervisor refuses to terminate a process using a persisted PID alone. If a previous service PID is still live, stop that previous service explicitly before starting another supervisor.

The Windows x64 archive contains the experimental TSF/server, native helpers, Python service source, pinned uv launcher, installation scripts, and hashed build manifest. Model weights are downloaded separately by the launcher. Verify the archive with `SHA256SUMS.txt`; `build-manifest.json` identifies the exact source commit. Publication is gated on Python tests, native CTest, bundle verification, and installation/launcher dry runs.

This is an experimental test bundle. Automated checks do not prove real-editor candidate visibility, digit selection, commit, paging, surrounding-context behavior, protected/password-field behavior, failure recovery, uninstall, or latency. Those target-machine manual smoke tests remain required. Service-only and offline latency measurements in the handoff are not real-editor acceptance.

After this baseline is published, GitHub #39 continues on a separate branch with opt-in FIM evaluation before any production-default change.
